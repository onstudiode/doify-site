Überblick

Die App doify erhebt keine personenbezogenen Daten für den Anbieter. Der Anbieter betreibt keine eigenen Server für die App und erhält keine deiner Aufgaben, Inhalte oder Nutzungsdaten.

Datenspeicherung

Deine Daten werden lokal auf deinem Gerät und in deiner privaten iCloud über Apple CloudKit gespeichert, damit sie auf deinen Geräten synchron bleiben. Auf diese Daten hat nur dein Apple-Konto Zugriff. Apple verarbeitet sie dabei als Auftragsverarbeiter nach der Datenschutzrichtlinie von Apple.

Benachrichtigungen

Erinnerungen werden lokal auf deinem Gerät geplant und angezeigt. Dafür werden keine Server verwendet.

Keine Werbung, kein Tracking, keine Analyse

doify enthält keine Werbung, keine Tracking-Dienste, keine Analyse-Werkzeuge und keine Software von Drittanbietern.

Deine Rechte nach DSGVO

Du hast das Recht auf Auskunft, Berichtigung und Löschung deiner Daten sowie das Recht, dich bei einer Datenschutz-Aufsichtsbehörde zu beschweren. Da der Anbieter keine personenbezogenen Daten von dir speichert, kannst du diese Rechte bezüglich deiner Aufgaben direkt in der App und in deiner iCloud ausüben. Bei Fragen schreibe an support@onstudio.de.

Löschung

Deinstalliere die App, um die lokalen Daten zu entfernen. Die Daten in iCloud entfernst du unter Einstellungen → Apple-ID → iCloud → Speicher verwalten, indem du die Daten von doify löschst.

Änderungen dieser Erklärung

Diese Erklärung kann angepasst werden, etwa bei neuen Funktionen. Die jeweils aktuelle Fassung findest du auf dieser Seite.
